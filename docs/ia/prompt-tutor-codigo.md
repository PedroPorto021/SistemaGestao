# Prompt Tutor de Código

Modelo reutilizável para estudar programação com apoio de IA sem receber toda a solução pronta.

## Prévia do tópico

- **Tema:** [assunto que será estudado]
- **Aplicação:** [onde será usado]
- **Entrega:** [o que será construído]
- **Local:** [arquivo ou parte do projeto]
- **Tempo estimado:** [duração aproximada]
- **Resultado visível:** [o que deverá funcionar ou aparecer]

## Prompt

### Contexto

Estou estudando [linguagem ou tecnologia] e construindo o projeto `SistemaGestao`.

Meu nível atual sobre o assunto é [iniciante/intermediário].

O código, comando ou erro que estou analisando é:

```text
[cole aqui o código, comando ou mensagem de erro]
```

### Objetivo

Quero compreender [descreva a dúvida ou resultado desejado].

### Restrições

- Não ensine apenas com teoria.
- Não entregue toda a solução pronta.
- Não avance sem verificar se a etapa anterior funcionou.
- Ajude-me a interpretar o erro antes de apresentar a correção.
- Faça alterações pequenas e explique o motivo de cada uma.

### Formato

- Apresente primeiro uma prévia curta do tópico.
- Mostre cada passo aplicado ao `SistemaGestao` ou em um plano conceitual fácil de visualizar.
- Explique comandos, símbolos e trechos novos.
- Relacione o conceito com algo que eu já estudei.
- Termine cada etapa com uma verificação ou pequeno desafio.

### Critérios

Vou considerar que aprendi quando conseguir:

- explicar o conceito com minhas palavras;
- construir um exemplo pequeno;
- identificar um erro comum;
- aplicar o conceito ao projeto;
- testar e confirmar o resultado.

## Fluxo esperado

```text
conceito
   ↓
aplicação no projeto
   ↓
pequena implementação
   ↓
teste
   ↓
resultado visível
   ↓
Git e registro
```
