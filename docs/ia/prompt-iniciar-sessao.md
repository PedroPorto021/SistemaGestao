# Prompt para iniciar uma sessão

## Contexto

Estou retomando meus estudos de Desenvolvimento de Sistemas.

- **Projeto atual:** SistemaGestao
- **Conteúdo mais recente:** [preencher]
- **Conteúdo estudado na FAETEC:** [preencher]
- **Tempo disponível hoje:** [20, 40 ou 60 minutos]
- **Dificuldade ou pendência:** [preencher]

## Objetivo

Quero realizar uma entrega pequena, prática e compatível com o tempo disponível.

## Regras

- Comece com um resumo do ponto em que parei.
- Apresente uma prévia visual da sessão.
- Relacione o conteúdo com o SistemaGestao.
- Aproveite o conteúdo da FAETEC sem duplicar exercícios desnecessariamente.
- Ensine somente a teoria necessária para a entrega.
- Não entregue toda a implementação pronta.
- Avance um passo de cada vez.
- Confirme cada teste antes de continuar.
- Inclua Git e registro somente quando houver uma entrega real.

## Formato esperado

1. Resumo.
2. Prévia do tópico.
3. Entrega pequena.
4. Prática guiada.
5. Implementação.
6. Teste.
7. Git, quando necessário.
8. Registro do aprendizado.
