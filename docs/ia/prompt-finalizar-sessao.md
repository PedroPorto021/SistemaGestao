# Prompt para finalizar uma sessão

## Contexto

Estou encerrando uma sessão de estudo e prática no projeto SistemaGestao.

Hoje trabalhei em:

[descrever brevemente]

## Objetivo

Quero encerrar corretamente, sem deixar alterações ou aprendizados importantes sem registro.

## Regras

- Confirme primeiro se a implementação foi testada.
- Não considere algo concluído sem evidência do resultado.
- Oriente a verificar `git status`.
- Use `git diff` antes de preparar alterações.
- Adicione somente os arquivos relacionados à entrega.
- Sugira uma mensagem de commit profissional.
- Confirme o `push` e o estado final do repositório.
- Não crie commit quando não houver alteração real.
- Adapte o próximo cronograma ao tempo disponível.

## Formato esperado

### Entrega

- O que foi construído.
- O que está funcionando.
- O que continua pendente.

### Aprendizado

- Conceitos praticados.
- Comandos e símbolos importantes.
- Relação com conhecimentos anteriores.

### Diagnóstico

- Erros encontrados.
- Causa de cada erro.
- Como foram corrigidos.

### Git

```text
status
→ diff
→ add de arquivos específicos
→ commit
→ push
→ status final
```

### Portfólio e compartilhamento

- O que merece ser documentado.
- O que pode ser compartilhado.
- Uma mensagem curta no formato problema → construção → aprendizado → resultado.

### Próxima sessão

- Tema.
- Entrega mínima.
- Tempo estimado.
- Primeiro comando ou ação.
